# v4.1.0 界面与前台提醒 · 2026-10-11

## 变更

- 老人端保留大号 SOS 入口；家人端优先展示正在处理的求助和未读留言。
- 家人消息默认显示列表，支持全部／未读／我发的筛选；发送文字和语音独立成编辑状态，返回列表保留本页未发送内容，发送失败不丢草稿。
- 语音播放按钮、消息确认按钮和回执层级更明确；删除自己的留言保持二次确认。
- 求助页优先展示正在处理的求助，已结束记录折叠。家人邀请以复制邀请码为主要操作，并说明分享不可用时的体验版入口。
- 统一前台检查，约每 8 秒一次；首页和消息页不再各自重复轮询。切到其他页面仍有角标、新消息提示和振动尝试；新 SOS 弹窗可前往回应；本人求助被家人确认也会提示。
- 前后台切换不会让过期响应弹窗；录音和页面提交期间推迟提示；同一提醒在本设备按成员去重。提示本身不产生已读或确认回执。
- 网络失败显示“新消息暂未更新”，恢复后清除。小程序退到后台时停止检查。

- 模拟器截图的 tabBar 图标显示异常，图标文件完整性检查通过；需要新预览在手机上确认最终显示。

## 真机检查

1. 两个账号都重新打开 v4.1.0，停留在不同页面，由另一方发送一条新留言。确认约一个检查周期后出现未读角标与提示；可能振动，取决于设备。
2. 进入家人消息，点“未读”，查看并主动确认；确认不会因弹出提示自动发生。
3. 提前约好 SOS 测试。家人端应弹窗，点查看进入求助页；家人确认后老人端得到提示。不要用真实急救电话做测试。
4. 录音期间收到消息，应待录音结束后提示；返回消息列表再进入编辑，检查未发送草稿。
5. 退到后台不应假定能收到通知。当前没有订阅模板，微信外部推送仍未开通。

此前用户已确认两个角色的消息收发、语音和 SOS 基本流程可用；最新纠正的问题是“缺少提醒”，没有确认消息丢失。因此本次未修改后端接收权限、长辈绑定或现有家庭数据。
