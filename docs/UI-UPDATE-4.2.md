# 家庭协作版 v4.2.0 · 2026-10-11

本版面向本人及受邀家庭成员，不提供公开服务、经营功能或企业管理后台。

## 使用变化

- “我的 → 家庭成员管理”分为成员、添加成员、本人资料。添加通过一次性邀请完成，家庭创建人可移除成员；移除前需要确认，既有生活记录保留。可单独撤销自己创建的邀请，创建人可以撤销全家的邀请。
- 两种角色都能给全家或指定的多名成员留言。指定留言及其录音仅发送者与选中的成员可读，家庭创建人也不能越权阅读。消息可搜索及筛选全部、未读、我发的、重要。
- 生活记录改成“一句话记事”：输入一句话，在本机按日期、称呼和活动关键词生成可修改的整理结果，确认后才保存。原文保留，不调用大模型，不自动保存。语音转文字可用手机输入法；现有录音留言功能保留。
- 新生活记录全家共同查看，可关联任意家庭成员；仅作者可修改或删除。旧记录保持原来的可见和编辑权限。搜索、我创建的筛选、分页和返回后本页草稿保留已实现。
- 按钮增加按压反馈；大字模式保留。收到新留言、求助或求助确认时，在前台尝试播放短提示音；“我的”可关闭或试听。录音/播放语音期间不插播，退到后台停止。

## 验证

- 33 项 Node 测试通过，包括定向消息与录音权限、移除成员后拒绝读取、共享记录作者权限、旧记录隔离、邀请撤销、日期解析、原生 Page.options 属性冲突回归、旧后端能力不足阻止发送和提示音去重/前后台行为。
- JS/JSON、10 个原生页面、绑定事件、条件和资源检查通过；开发者工具内置 WXML/WXSS 编译通过。
- 微信模拟器使用本地虚构成员点击“一句话记事”、输入、整理，确认“昨天陪测试家人散步了半小时”得到 2026-10-10、测试家人、陪伴记录。
- 模拟器检查了老人端指定成员、成员管理/邀请的大字模式、提示音设置；试听调用后无音频错误。修复了关联成员为空和接收范围按钮排版问题。
- 模拟数据仅注入本地运行时，未写入真实数据库、未发送消息或求助。验收后已重新进入真实登录页，恢复前台检查。
- 自动化连接刷新后偶发超时，后续调用恢复；未将超时当作业务通过。

## 升级与剩余验收

需要先部署 warmcare，确认真实 session 的 capabilities，再上传前端。无需新建集合，旧数据保留。当前状态见 DEPLOYMENT-STATUS.md；部署确认不等于正式发布。

新功能尚待升级后的两个/三个不同微信账号验证：全家/指定成员文字和语音、共享记录和作者权限、邀请/移除、手机提示音和静音设置。模拟器测试不能替代真机收发和听感。

微信订阅消息模板仍未配置，当前提示音和提醒仅在小程序前台工作，不能保证后台提醒或救助；紧急情况仍需主动电话联系。
