# v4.0.0 验收记录 · 2026-10-10

2026-10-11 补充：用户已确认双端消息、语音和 SOS 流程基本可用。v4.1.0 的提醒与界面更新、24 项测试和剩余真机验收见 [UI-UPDATE-4.1.md](UI-UPDATE-4.1.md)。下面为初版检查历史。

## 已完成

- `npm test`：17 项测试通过。涵盖可信微信身份、创建人限制、邀请码限用一次、角色不可伪造、多位家人分别确认 SOS、没有订阅模板时不伪装发送、发送与已读分离、长辈数据隔离、语音权限及删除、成员撤销、请求防重、客户端断网重试、家庭记录 CRUD。
- `npm run check`：10 个原生页面的 JS/JSON、事件绑定、条件表达式、路由与资源，以及前后端共享规则一致性通过。
- 微信开发者工具自带 WXML/WXSS 编译器：全部模板与样式编译通过。
- 微信模拟器：使用独立测试夹具检查老人端、家人端和求助页面，验证文字输入事件。测试夹具保存在开发目录 `artifacts/`，不进入交付包，不发送真实消息、不拨号。
- 发现并修复按钮宽度、空状态与非空内容同时出现的显示问题。条件统计由 JS 明确计算后绑定。

## 真实云端检查与修复

- 开发用云环境的集合列表为空（本次修改时查询）。
- 现有线上 `warmcare` 调用失败：旧入口依赖 `./lib/service`，模块缺失。本版新入口改用 `lib/family`，需要完整部署替换旧函数。
- 完整部署后发现子目录模块仍无法加载，已改为单文件入口；再次部署后真实 identity 接口调用成功。
- 用户随后确认三项控制台配置完成。函数元数据确认超时为 30 秒；真实登录页已显示创建人专属的家庭创建表单。集合和云存储权限依据用户确认，客户端越权访问实测尚未完成。
- 本次模拟器自动化执行接口超时，一次重新编译后仍未恢复；截图正常。当前不能据此宣称真实家庭创建、语音和多账号收发已验收。
- 用户确认订阅消息模板尚未配置，因此当前不能声称微信推送已可用。

## 待完成的验收

完整云部署后，用至少两台手机/不同微信账号验证邀请加入、语音录制与播放、重要消息确认和 SOS 确认。模板开通后验证微信通知，覆盖未授权和断网状态。模拟器测试不能替代这些检查。

实际云部署进度以 `DEPLOYMENT-STATUS.md` 为准；源码完成与云端可用必须分别判断。
